# Historical assets

Daniel Bişar created the Medja flyer and screenshots. They are retained as
historical engineering and presentation material for the employer-supported
project, whose source publication was authorized by SprintWORX GmbH.

| Asset | Context | Presentation status |
| --- | --- | --- |
| `screens/demo.png` | Standard controls and their normal, touched, disabled and focused states | Customer-neutral overview image used in the README. |
| `screens/3dgraph.png` and `.xcf` | Historical rendered graph and editable GIMP source | No visible customer name; retained as historical graphics illustrations. Data provenance is not established by the image. |
| `screens/embedded_app1.png` and `.xcf` | Sensor-oriented application UI and editable source | No visible customer name; application/data context needs manual confirmation before wider promotion. Not used as the README hero image. |
| `flyer.pdf` and `flyer.odg` | 2019 SprintWORX marketing flyer and editable LibreOffice source | Archived, not current product documentation or a support matrix. |

The flyer includes historical business contact details (company address, sales
email, telephone number, CEO and registration details). These are not presented
as current project contacts. It also includes broad architecture/OS ambitions and
animation/performance wording that must not be read as verified current
capabilities. The README defines the current verification scope instead.

The PDF embeds Liberation Sans 1.07.4 font subsets. Font licensing differs from
the project MIT license; see [third-party notices](../THIRD-PARTY-NOTICES.md).
Other font names in the ODG style definitions do not alone establish that font
software is embedded.

The asset review found no customer-name text in the flyer PDF/ODG or the inspected
screenshots/source metadata. It does not establish that every plotted value is
synthetic. Existing imagery is not evidence of customer endorsement, production
scale, or commercial results.
